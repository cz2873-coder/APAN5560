# LLM Fine-Tuning Project

This repository contains example code for fine-tuning GPT-2 and integrating it
into a FastAPI endpoint as required for Assignment 5 (Post-Training an LLM).

## Files

- `fine_tune.py`: Example script showing how GPT-2 can be fine-tuned using a QA dataset.
- `api.py`: FastAPI application exposing the `/generate_with_llm` endpoint.
- `requirements.txt`: Dependency list.
- `README.md`: Overview of the project.

## Notes
The code in this repository is illustrative and does not need to be executed
for the assignment. The purpose is to demonstrate understanding of the fine-tuning workflow and API integration.
